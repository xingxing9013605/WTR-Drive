# Concept figure

`overview.png` is the World–Task–Risk concept figure from the WTR-Drive manuscript. It is drawn from geometric elements and contains no dataset camera frames.

- **(a) World:** all candidates share one scene estimate.
- **(b) Task:** candidates p₁ (teal, solid) and p₂ (orange, dashed) read the shared Task Memory.
- **(c) Risk:** only p₂ collides with object A at t*; the orange footprint marks the ego vehicle at first contact.

This is a schematic. Its trajectories and arrows do not encode a measured driving rollout or numeric attention weights. Benchmark results are reported separately in the [README](../README.md#reported-results).
